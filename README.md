# Necropolis-Arcanist-Animation-Patch
A patch to force Arcanist to use Brute animations instead of softlocking the game whenever you do something that is unfinished.

# Installation
Install from [Thunderstore](https://thunderstore.io/c/necropolis/p/GrArmpit/ArcanistAnimFix/) using your favorite mod manager. Depends on Deadjak's Custom Adventurers to enable the Arcanist in the first place, as well as BepinEx of course.

# Status
I haven't played through the entire game with it yet, so if there is a blocker let me know. At least through the first level, though, game is playable if slightly uncomfy.
